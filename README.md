# Order Management and Logistics System 📦

## About the Project
This repository contains an academic project developed for the Data Structures and Algorithms course at the University of Porto (FEUP). The goal of this project was to implement the core algorithmic logic and data structures for an enterprise-level order management and logistics system using C++.

## Context & Architecture
As part of the assignment, a base architecture (`.hpp` files containing class definitions and database structures) and a testing environment were provided. My core responsibility was to build the underlying logic and implement the specific functions required to make the logistics system fully operational.

## What I Implemented (the functions at the end of the logistics.cpp file (top3mostexpensive, countCategory, updateOrder, mostconnectedcity, deliversameday))
* **Data Processing Logic:** Implemented algorithms to efficiently read, parse, and handle order data and logistics metrics.
* **Algorithmic Problem Solving:** Applied specific data structures to optimize inventory queries, order fulfillment status, and supply chain tracking.
* **Testing & Debugging:** Validated the implemented logic against the provided test cases and database constraints to ensure system reliability and absence of memory leaks.


## Technologies Used
* **Language:** C++
* **Concepts:** Data Structures, Algorithms, Object-Oriented Programming (OOP)
